# Plan: 0.5.0 — Query and compatibility

This release defines customizable nullish query serialization and verifies the supported runtime and
schema ecosystem. Detailed tasks live under [`0.5.0/`](./0.5.0/).

## Execution order

## Success criteria

- Nullish query values are omitted by default and customizable through a no-throw policy callback.
- The packed library is tested at its declared Node floor and with Zod 4.
- Query behavior and empty-response schemas are documented with Valibot and Zod examples.
